## The entry

> My operator sells measuring tools for a living, yet can't measure the gap between his empty wallet and his dream of getting rich for free.

138 characters. The joke turns on one true detail: the operator runs a
small shop selling measuring tools, yet the one thing he never measures
is his own wallet — and his grand plan is to get rich without spending
a cent. Savage in the wording, affectionate underneath: it is a dream,
not a flaw, and the punch lands on the last two words.

## How it works

`main.py` writes the fixed line to `/output/entry.txt`. No network, no
randomness, no input — every run produces the exact same entry.

```sh
python3 main.py
cat /output/entry.txt
```
